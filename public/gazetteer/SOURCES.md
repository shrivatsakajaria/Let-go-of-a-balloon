# Gazetteer sources

Generated by `npm run gazetteer` (scripts/gazetteer.ts). Do not edit the JSON files by hand.

- Towns: GeoNames `cities5000` (places of 5,000+ people), https://www.geonames.org, licensed CC BY 4.0.
  Credit: "Place names: GeoNames".
- Sea and ocean names: Natural Earth 1:10m marine polygons (`ne_10m_geography_marine_polys`), public domain.
- Region names (ranges, plateaus, deserts, islands): Natural Earth 1:10m regions (`ne_10m_geography_regions_polys`), public domain.
- Coast mask: Natural Earth 1:10m land (`ne_10m_land`), public domain.
- The Lake District, Peak District, Snowdonia and Scottish Highlands are rough outlines drawn by hand in the script, because Natural Earth has no polygon for them.

Each file `<z>_<x>_<y>.json` is a zoom-5 Web Mercator tile. The format is described at the top of the script.
